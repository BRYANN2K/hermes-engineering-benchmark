# Benchmark results

Published LLM Engineering Benchmark campaigns are stored by execution date. Each release keeps its reports, machine-readable data, charts and checksums together.

| Date | Campaign | Tasks | Routes | Verified runs | Winner | Report |
|---|---|---:|---:|---:|---|---|
| 2026-08-14 | `campaign-20260814-v4` | 40 | 6 | 360/360 | Daybreak Blue — 37/40 | [Open release](2026-08-14-v4/) |

Campaign directories are immutable publication snapshots. A changed suite, harness, route roster, grader or scoring rule requires a new dated release rather than an edit to an existing result.
